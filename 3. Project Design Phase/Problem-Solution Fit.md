# Problem-Solution Fit

**Project:** EduGenie – Your Smart Budget & Recommendation Assistant  
**Team ID:** SWTID-2026-5933

| Canvas Element | EduGenie Details |
|---|---|
| Customer Segment(s) | Students, young professionals and families managing monthly budgets |
| Jobs-to-be-Done / Problems | Track spending, stay within budget, save more, decide on purchases |
| Triggers | Month-end shortage, large purchase, new job or allowance, savings goal |
| Emotions: Before | Stressed, guilty, uncertain |
| Emotions: After | In control, confident, motivated |
| Available Solutions | Notebooks, spreadsheets, bank apps, generic finance apps |
| Problem Root Cause | Manual tracking, no early warnings and no personalised advice |
| Customer Constraints | Limited income, limited time, privacy concerns |
| Behaviour | Checks bank balance, notes a few expenses, compares prices |
| Your Solution | AI assistant that tracks expenses, plans budgets, forecasts spending and gives personalised recommendations |
| Channels of Behaviour (Online) | UPI apps, bank apps, shopping sites, web browser |
| Channels of Behaviour (Offline) | Discussions with family and friends, paper notes |
| Team | Punitha K (Leader), Madhan, Haridha, Shameem S |
