# Proposed Solution

**Project:** EduGenie – Your Smart Budget & Recommendation Assistant  
**Team ID:** SWTID-2026-5933

| S.No | Parameter | Description |
|---|---|---|
| 1 | Problem Statement (Problem to be solved) | People struggle to track spending, stay within budgets and find personalised ways to save |
| 2 | Idea / Solution Description | A web-based assistant that categorises expenses with ML, forecasts future spending and uses generative AI to give personalised saving recommendations and answer budget questions |
| 3 | Novelty / Uniqueness | Combines expense tracking, budget alerts, forecasting and conversational recommendations in one simple tool built around the user's own data |
| 4 | Social Impact / Customer Satisfaction | Improves financial awareness, reduces month-end stress and encourages savings habits among students and young earners |
| 5 | Business Model (Revenue Model) | Free basic plan; premium plan with advanced forecasts, goals and reports; partnerships for relevant offers and recommendations |
| 6 | Scalability of the Solution | Modular backend and cloud database support more users; new categories, currencies and models can be added without changing the whole system |
