## 3. Project Overview

| Section | Description |
|---|---|
| Introduction | EduGenie is an AI-based assistant that helps users track expenses, plan budgets and receive personalised saving recommendations |
| Problem | People lack simple, personalised tools to control spending and save money |
| Objective | Provide expense tracking, auto-categorisation, budget alerts, forecasting and AI recommendations in one application |
| Technology | Python, Flask, scikit-learn, Google Gemini API, HTML, CSS, JavaScript, database |
| Users | Students, young professionals and families |

## 4. Features

| S.No | Feature | Benefit |
|---|---|---|
| 1 | Expense Tracking | Clear view of where money goes |
| 2 | Auto Categorisation | Saves time on data entry |
| 3 | Budget Alerts | Prevents overspending |
| 4 | Spending Forecast | Helps plan ahead |
| 5 | AI Recommendations | Personalised ways to save |
| 6 | Budget Chat | Quick answers to money questions |

## 5. Advantages and Limitations

| Advantages | Limitations |
|---|---|
| Personalised to the user's own data | Forecast needs a few months of data to be accurate |
| Saves time through automation | AI advice is guidance, not professional financial advice |
| Simple and easy to use | Depends on generative AI API availability |
